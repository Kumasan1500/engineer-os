# Engineer OS v0.8 — Career OS

v0.8 connects learning evidence to career evidence.

## Added in v0.8
- Role Readiness for Cloud Engineer / SRE / Cloud Security Engineer
- Weighted skill-gap analysis
- Practical portfolio projects
- GitHub / demo / reflection evidence capture
- Evidence-gated project completion
- 3–4 year career milestone roadmap
- Career OS dashboard linked from Home

## Upgrade from v0.7
1. Copy `.env.local` from v0.7 into this `engineer-os` folder.
2. Run `sql/v0.8_career_os.sql` in Supabase SQL Editor.
3. Run `npm.cmd install`.
4. Run `npm.cmd run dev`.

No `content:sync` is required for this upgrade.

> Role Readiness is a training/navigation signal, not a salary or hiring guarantee. It intentionally requires skill retention plus practical evidence.
